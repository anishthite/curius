Decisions

IDChoice · Rationale
D-001Use event-to-next-frame p90. It maps directly to perceived input responsiveness.
D-002Patch the generator. Generated pages must keep the optimization after scheduled rebuilds.
D-003Optimize graph redraw first. It is the measured bottleneck by more than one frame.
D-004Regenerate current pages from embedded JSON. The workspace has no local data/curius.sqlite.
D-005Supersedes: D-004. Copy /Users/anishthite/workspace/curious-index/data/curius.sqlite and run the full generator.
D-006Use bitmap preview during active pan/zoom. Continuous movement should transform the current frame before the exact graph redraw settles.
D-007Supersedes: D-006. Use Sigma 3.0.3 and Graphology 0.26.0 for the follower graph. WebGL camera motion fits the user's request for a rendering-library-backed graph.
D-008Materialize node and edge display attributes outside render reducers. Camera movement must not recompute filtering and relation colors for every primitive per frame.
D-009Cap the graph renderer pixel ratio at 1x. Dense dots and edges favor pan latency over retina-sharp backing buffers.
D-010Supersedes: D-007, D-008, D-009. Replace Sigma with a dependency-free custom WebGL renderer plus 2D overlay. It restores the old visual language while keeping GPU-backed dense primitives.
D-011Add a movement-only render path. Active pan and wheel render WebGL primitives only, then restore overlay labels and status after movement settles.

Tradeoffs

IDPicked over Rejected · Reason
T-001requestAnimationFrame-scheduled canvas draws over synchronous pointer draws. Pointer handlers return before paint-heavy work.
T-002Precomputed frontpage top-50 views over client sorting. Static generation already knows the ranking inputs.
T-003Cached bitmap preview over exact redraw on every move. It prioritizes pan/zoom feel while preserving exact redraw after interaction idle.
T-004Pinned CDN ESM imports over vendored browser bundles. The static app avoids a build step while keeping exact dependency versions.
T-005hideEdgesOnMove over full edge redraw during camera motion. Drag/zoom responsiveness matters more than seeing all edges while the viewport is moving.
T-006WebGL points and lines with a 2D label/arrow overlay over all-WebGL text. Browser canvas text preserves the old serif label rendering.
T-007Cap WebGL backing pixels at 1.5x while leaving overlay text at native DPR. Dense graph motion gets fewer pixels without blurring idle labels.

Assumptions

  • A-002 · Direct DOM dispatch to Sigma's .sigma-mouse layer is representative for relative pan/wheel latency. Playwright's native mouse driver hung in this headless environment.
