Algorithm

  1. Track active pointer positions in activePointers.
  2. Start pinch when two pointers are down; store start distance, scale, and world point under the midpoint.
  3. On move, set view.scale = clamp(startScale * currentDistance / startDistance).
  4. Set view.x/y so the stored world point remains under the current pinch midpoint.

UI layout

  1. Toolbar: increase mobile gaps and control height.
  2. Graph: increase mobile canvas height from 46vh to 52vh.
  3. Reader: add mobile top gap and larger row padding.
