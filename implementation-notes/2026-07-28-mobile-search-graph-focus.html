Algorithm

  1. After a mobile search result selects id, run focusNode(id).
  2. Set view.x/y to place the node near the graph center and set view.scale to a mobile focus scale.
  3. Refresh buffers without changing mode or filtering semantics.

UI layout

  1. Search: collapse results after selection so the canvas does not resize under the tap.
  2. Graph: use a larger mobile canvas with less intrusive status chrome.
  3. Labels: show only selected/hover labels at normal mobile focus scale.
  4. Reader: draw selected details as a simple mobile sheet with larger list rows.
