Decisions

IDChoice · Rationale
D-001Use CSS bounds only. The request is layout sizing, not graph behavior.
D-002Widen sidebar to 240-285px. Screenshot review showed spare horizontal space.
D-003Make lists taller inside the fixed viewport cap. More rows show without restoring page-level scroll.
D-004Offset sidebar upward instead of moving the graph section. The graph frame stays stable while the reader starts near the control row.
D-005Use a fixed right drawer for desktop. The user wants the sidebar at the top edge and visually separate from the graph plane.
D-006Make scrollability visual in the drawer lists. A fade and stable gutter signal more rows without adding instruction copy.
D-007Keep search result cards at 320px max on tablet and desktop. Single results should not stretch across the tray.
D-008Resize graph when search results are open. The no-page-scroll constraint still applies to search state.
D-009Use compact but non-cramped result padding. The search cards should read as clickable pills, not content cards.
